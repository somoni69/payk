# payk

A Flutter mobile application for the Payk Loyalty Platform (UDC Design System).

## Demo Account for App Store Review

```text
Demo Account for App Store Review:
1. Enter phone number: 900000000 (country prefix +992 is preset in the app).
2. Tap "Получить код" (Get code).
3. On the SMS code verification screen, enter: 111111
This test account bypasses SMS delivery and provides full access with sample loyalty balance, QR code, and transaction history.
```
